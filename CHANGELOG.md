# Changelog

All notable changes to the Copperpot Bowls app are recorded here. The format follows Keep a Changelog; versions follow the app-store build.

## [1.1.0] - 2024-06-07

### Added

- Store picker with the pilot stores and order-ahead availability
- Bowls, burritos, sides and drinks menu with a category filter
- One cart per store, kept across screens

### Changed

- Source moved under src/ with one folder per feature module
- Brand, colours and copy for Copperpot Bowls

## [1.0.2] - 2024-05-24

Handover build from the agency: home screen with offers, cart badge, fonts and styling system.
